# DTaaS · Северо-Запад

Многостраничный сайт цифровой трансформации СЗБ. HTML, CSS и JavaScript; установка пакетов не требуется.

## Запуск и публикация

Node.js 20+: `npm start`. Сервер слушает порт 3000; другой порт задаётся через `PORT`.

GitHub Pages публикует папку `public` после push в `main`: workflow `.github/workflows/pages.yml` проверяет данные и загружает статические файлы. В Settings → Pages выбран источник GitHub Actions.

- Мероприятия: `https://fot-manager-training.github.io/CSM/events.html`.
- Кейсы: `https://fot-manager-training.github.io/CSM/cases.html`.
- Партнёры: `https://fot-manager-training.github.io/CSM/partners.html`.

Главная страница `index.html` снова содержит выбранную пользователем композицию: волну и крупный заголовок, круглую ленту событий, раскрывающиеся превью кейсов и ленту партнёров. Полные каталоги остаются самостоятельными страницами. Пункт «Главная» и логотипы ведут на `index.html`. Каждая страница загружается напрямую и после обновления браузера без серверных перенаправлений. Старые ссылки `#events`, `#cases`, `#partners`, `#case/...` и `#partner/...` перенаправляются в соответствующий HTML-документ.

## Интерфейс

Общая палитра интерфейса: белый, графитовый и синий. Начертания SB Sans Display 300/400/700 предоставлены пользователем и подключены локально. Основной стиль — `public/site.css`; старые `styles.css` и `theme.css` не подключаются.

Шапка закреплена на всех страницах: логотипы Сбера и DTaaS слева, «Мои события» и «Меню» справа. У неё прозрачный фон без цветной панели и размытия. Меню раскрывается отдельными овальными ссылками по референсу social-project c9418df, используя общую палитру сайта. Реализация — `navigation.js` и `navigation.css`. Поддержаны Escape, закрытие вне меню, клавиатура, inert и reduced motion.

Афиша организована по предоставленному скриншоту Яндекс Афиши: строка поиска и город, горизонтальные категории, прокручиваемая лента дат, «Все фильтры» и тип события, крупные листаемые карточки и общий каталог. Лента дат работает мышью и касанием; перетаскивание не выбирает дату случайно. Дата, город, тип, поисковый запрос и избранное комбинируются. У AI Journey выбор 27 и 28 ноября показывает одно двухдневное событие. Выходные помечены отдельно, день недели вычисляется для 2026 года; текущая дата учитывает Europe/Moscow. Контроллер новой афиши — `afisha.js`, оформление — `afisha.css`.

Круглая лента событий сохранена на главной: мышь, свайп, клавиатура и пауза вращения. Избранное сохраняется в localStorage; кнопка из других разделов открывает страницу мероприятий с сохранёнными событиями. Подробности доступны по ссылке `events.html#event/aij`; сохранены календарь, экспорт .ics и копирование ссылки.

Кейсы и партнёры не выводятся блоками на странице афиши. Их каталоги находятся на самостоятельных страницах с поиском, совместными фильтрами, загрузкой следующих карточек и подробностями. Примеры ссылок: `cases.html#case/case-02`, `partners.html#partner/partner-1` (ID партнёров соответствуют исходным материалам).

По последним указаниям пользователя кот удалён со всех страниц, его модель и WebGL-библиотека не загружаются. Убраны рекламный блок внизу главной, вводные плашки и счётчики каталогов, отдельная панель избранных кейсов, ссылки на исходный кейсбук под каталогом и декоративные сезонные подписи. Поиск, фильтры, карточки, сохранение отдельных кейсов и их исходные показатели сохранены. На главной фон заставки продолжается под прозрачной закреплённой шапкой, затем градиентом переходит в белый фон мероприятий.

## Данные и изображения

Все 20 кейсов и 68 партнёров перенесены из предоставленных пользователем текстов в `public/content.js`. Сохранены исходные номера (включая кейс 23 «Самокат»), незаполненные поля и контекст метрик: цель, заявление, MVP, пилот, качественный эффект. Поисковая логика — `catalog-data.js`, интерфейс — `catalog.js`.

Пять событий заданы пользователем в `data.js`. Королевский акселератор — Санкт-Петербург, 10 декабря. Год в исходном задании не указан: принят сезон 2026. Точное время, адреса, цены, программа и регистрация не предоставлены; эти поля не выдуманы. .ics использует даты без времени; AIJ экспортируется как двухдневное событие с исключающей датой окончания.

Сайт-источник кейсов и партнёров: https://sber-northwest-casebook.tenderlion1.chatgpt.site/#practice

Материалы стиля: https://files.sberdisk.ru/s/k3OodMv51eGOhlx

В среде эти два сайта недоступны через прокси, а предоставленная презентация превысила лимит передачи 32 МиБ. Пользователь затем предоставил отдельные тексты, шрифты и скриншоты. Киберкот и логотипы очищены и масштабированы из скриншотов, а не извлечены из PPTX.

В `assets/events/` — пять иллюстративных обложек событий, в `assets/cases/` — 20 индивидуальных иллюстраций кейсов. Общие баннеры сохранены в `assets/scenes/`. Карточки партнёров используют тематические изображения компетенций. Это сгенерированные редакционные иллюстрации, а не фотографии реальных внедрений, подтверждение площадок или портреты сотрудников. Новые 22 изображения кейсов и общих сцен занимают около 2 МБ в WebP. Внешние CDN не используются.

Серверной регистрации, личных кабинетов и CMS нет. Избранное локальное; данные не обновляются автоматически. Дополнительные 7 проектов других регионов и контакты партнёров не были предоставлены и не добавлялись.

## Проверки

`npm test` — 14 проверок данных, фильтров, контекста метрик, экспорта календаря и самостоятельных HTML-страниц.

Для браузерных проверок запустите сайт и Chromium с remote debugging на порту 9222. Сценарии используют одну вкладку и запускаются последовательно:

```sh
node tests/browser.mjs
node tests/home-browser.mjs
node tests/navigation-browser.mjs
node tests/afisha-browser.mjs
```

По умолчанию проверяется `http://127.0.0.1:3000/`. Переменная `APP_URL` позволяет проверить подпапку Pages, например `APP_URL=http://127.0.0.1:3001/CSM/`. Проверяются реальные переходы, фильтры, избранное между страницами, календарь, детали, ввод мышью и касанием, прозрачная фиксированная шапка, отсутствие переполнения при 320/390/768/1440 px, загрузка шрифтов/изображений, удаление кота и отсутствие загрузки WebGL, выбор дат, комбинированные фильтры и горизонтальное листание. Снимки сохраняются в игнорируемую папку `artifacts/`.

Обложка Королевского акселератора — отдельно сгенерированная иллюстрация Санкт-Петербурга в `assets/events/royal-spb.webp`. Карточка, подробности, крупная подборка афиши и круглая лента на главной берут её из общего `eventImages.royal` в `media.js`.
