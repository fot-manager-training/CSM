# DTaaS · Северо-Запад

Адаптивная платформа цифровой трансформации СЗБ. Приложение на HTML, CSS и JavaScript без внешних зависимостей и сетевых ресурсов.

## Запуск

Требуется Node.js 20 или новее. Из `/workspace/CSM`:

```sh
npm start
```

Сервер слушает порт 3000 (можно изменить через `PORT`). Установка пакетов не требуется.

## GitHub Pages

В настройках репозитория `Settings → Pages → Build and deployment → Source` выберите **GitHub Actions**. Workflow `.github/workflows/pages.yml` запускает тесты, загружает только папку `public` и публикует её после обновления `main`. Также доступен ручной запуск `Run workflow` во вкладке Actions. Сервер Node.js на GitHub Pages не нужен.

Ожидаемый адрес после успешной публикации: `https://fot-manager-training.github.io/CSM/`. Все локальные ресурсы используют относительные пути для работы в подпапке `/CSM/`; навигация использует hash, поэтому ссылки на события не требуют серверных перенаправлений.

## Возможности

- Разделы «Мероприятия», «Кейсбук», «Партнёры»: 20 кейсов и 68 партнёров из предоставленных пользователем материалов.
- Поиск и совместные фильтры кейсов по задаче бизнеса и контексту показателей, отдельное избранное.
- Поиск партнёров по названию и ИНН, фильтры технологий, типа и аккредитации; подробности в диалоге.
- Локальные SB Sans Display Regular (400), Bold (700), Light (300) во всём интерфейсе.
- Светлая голубая/персиковая/оранжевая палитра по выбранным фрагментам референсов: первый экран с волной, круглая лента обложек событий, карточки с изображениями, раскрывающаяся лента кейсов и карточки партнёров поверх большого заголовка; при prefers-reduced-motion анимация отключена.
- Пять событий из задания, поиск, совместные фильтры по формату, региону и месяцу. Королевский акселератор проходит в Санкт-Петербурге.
- Иллюстративные обложки событий и календарь ноября / декабря 2026 года. В кейсбуке и каталоге партнёров первый экран скрыт, чтобы сразу показывать содержимое раздела.
- Избранное в localStorage браузера, включая синхронизацию между вкладками.
- Подробности события, прямая ссылка, экспорт в .ics. AIJ экспортируется как двухдневное событие.
- Адаптивная вёрстка, клавиатурная навигация, диалог с удержанием фокуса, поддержка reduced motion.
- 20 отдельных иллюстраций кейсов, два баннера каталогов и тематические изображения компетенций партнёров. Все 22 новых WebP занимают суммарно около 2 МБ.
- Круглая карусель событий плавно вращается по кругу; поддерживает мышь, свайп, горизонтальный жест трекпада и клавиатуру. Перетаскивание не открывает карточку; есть пауза, остановка вне экрана, при фокусе/наведении, в скрытой вкладке и при открытом диалоге. При reduced motion автовращение отключено.
- Локальные иллюстративные изображения в WebP, CSS-анимация и SVG-волна: внешние шрифты и изображения не нужны. Волна приостанавливается при prefers-reduced-motion и скрытии вкладки.

## Проверка

```sh
npm test
```

Десять проверок данных, фильтров, контекста показателей и экспорта календаря. Для проверки через Chromium запустите приложение и Chromium с remote debugging на порту 9222, затем `node tests/browser.mjs`. Проверка открывает страницу, проверяет основные взаимодействия и отсутствие горизонтального переполнения на 390, 768 и 1440 px, проверяет реальное перетаскивание мышью, свайп, переход через край карусели, загрузку всех 22 новых иллюстраций в подпапке Pages и всех трёх начертаний SB Sans Display и сохраняет снимки в игнорируемую папку `artifacts/`. Переменная `APP_URL` позволяет проверить размещение в подпапке, например `APP_URL=http://127.0.0.1:3001/CSM/ node tests/browser.mjs`.

## Содержимое и ограничения

Данные событий: `public/data.js`. Год в задании не указан: принят 2026 по текущему сезону. Время, адреса, программа, цены и ссылки регистрации не предоставлены и не выдуманы. Экспорт календаря использует даты без времени.

Сайт кейсов: https://sber-northwest-casebook.tenderlion1.chatgpt.site/#practice

Материалы стиля: https://files.sberdisk.ru/s/k3OodMv51eGOhlx

Оба сайта пока заблокированы сетевым прокси среды (CONNECT 403), а «стиль.pptx» превышает лимит передачи инструмента 32 МиБ. По последнему выбору пользователя применена светлая палитра из новых фрагментов референсов: голубой, персиковый и яркий оранжевый. Воспроизведены отдельные элементы — волна за заголовком, круглая лента событий, карточки с обложками, раскрывающийся аккордеон кейсов и прокручиваемая лента партнёров перед большим фоновым заголовком. Контролы работают с существующими данными; исходные показатели кейсов и их контекст сохранены. Версия URL стилей и точки входа JavaScript обновлена, чтобы браузер загружал актуальный макет. `public/styles.css` содержит базовую вёрстку, `public/theme.css` — оформление по референсам. Вместо недоступной презентации использован отдельный скриншот киберкота. Изображения киберкота и логотипов Сбера и DTaaS очищены и масштабированы по приложенным скриншотам инструментом редактирования изображений; они находятся в `public/assets/`. Это обработанные изображения, не извлечённые оригиналы из PPTX. Шрифты предоставлены пользователем отдельно и подключены локально из `public/fonts/`.

Все 20 кейсов и 68 партнёров перенесены из двух предоставленных пользователем текстовых файлов в `public/content.js`. Поисковая логика — `public/catalog-data.js`, интерфейс каталогов — `public/catalog.js`. Контекст метрик (цель, заявление, MVP, пилот, качественный эффект) и незаполненные поля сохранены. Номера кейсов соответствуют исходнику, включая кейс 23 «Самокат». Упомянутые в исходнике остальные 7 проектов других регионов не были приложены и не добавлялись. Контакты и отдельные сайты партнёров не предоставлены; ссылки на сайт-источник ведут на общий кейсбук.

Приложение не содержит серверной регистрации, личных кабинетов и CMS. Сохранение избранного локальное; события не обновляются автоматически.


Интерактивные блоки главной страницы находятся в `public/showcase.js`, пути к обложкам — в `public/media.js`. Изображения в `public/assets/events/*.webp` созданы как рекламные иллюстрации; они не являются фотографиями прошедших мероприятий или подтверждением площадок. Они сжаты в WebP из исходных PNG без изменения композиции. Логотипы компаний-партнёров и фотографии их сотрудников не предоставлены: в карточках используются названия, типографические инициалы и тематические иллюстрации компетенций без вымышленных портретов и логотипов. Для кейсов добавлены индивидуальные обложки в `public/assets/cases/`, общие баннеры находятся в `public/assets/scenes/`. Они созданы инструментом генерации изображений как редакционные иллюстрации; это не фотографии реальных помещений клиентов или внедрённых систем. Исходные тексты и метрики кейсов сохранены.
