# DTaaS · Северо-Запад

Адаптивная платформа цифровой трансформации СЗБ. Приложение на HTML, CSS и JavaScript без внешних зависимостей и сетевых ресурсов.

## Запуск

Требуется Node.js 20 или новее. Из `/workspace/CSM`:

```sh
npm start
```

Сервер слушает порт 3000 (можно изменить через `PORT`). Установка пакетов не требуется.

## GitHub Pages

В настройках репозитория `Settings → Pages → Build and deployment → Source` выберите **GitHub Actions**. Workflow `.github/workflows/pages.yml` запускает тесты, загружает только папку `public` и публикует её после обновления `main`. Также доступен ручной запуск `Run workflow` во вкладке Actions. Сервер Node.js на GitHub Pages не нужен.

Ожидаемый адрес после успешной публикации: `https://fot-manager-training.github.io/CSM/`. Все локальные ресурсы используют относительные пути для работы в подпапке `/CSM/`; навигация использует hash, поэтому ссылки на события не требуют серверных перенаправлений.

## Возможности

- Разделы «Мероприятия», «Кейсбук», «Партнёры»: 20 кейсов и 68 партнёров из предоставленных пользователем материалов.
- Поиск и совместные фильтры кейсов по задаче бизнеса и контексту показателей, отдельное избранное.
- Поиск партнёров по названию и ИНН, фильтры технологий, типа и аккредитации; подробности в диалоге.
- Локальные SB Sans Display Regular (400), Bold (700), Light (300) во всём интерфейсе.
- Тёмная композиция по второму референсу: крупная типографика, асимметричная мозаика с киберкотом, цветные блоки без панелей управления, реакция декоративного глаза на курсор и плавная анимация; при prefers-reduced-motion анимация отключена.
- Пять событий из задания, поиск, совместные фильтры по формату, региону и месяцу.
- Крупные постеры событий и календарь ноября / декабря 2026 года. В кейсбуке и каталоге партнёров первый экран скрыт, чтобы сразу показывать содержимое раздела.
- Избранное в localStorage браузера, включая синхронизацию между вкладками.
- Подробности события, прямая ссылка, экспорт в .ics. AIJ экспортируется как двухдневное событие.
- Адаптивная вёрстка, клавиатурная навигация, диалог с удержанием фокуса, поддержка reduced motion.
- Локальные SVG-постеры и CSS-анимация: внешние шрифты и изображения не нужны.

## Проверка

```sh
npm test
```

Девять проверок данных, фильтров, контекста показателей и экспорта календаря. Для проверки через Chromium запустите приложение и Chromium с remote debugging на порту 9222, затем `node tests/browser.mjs`. Проверка открывает страницу, проверяет основные взаимодействия и отсутствие горизонтального переполнения на 390, 768 и 1440 px, проверяет загрузку всех трёх начертаний SB Sans Display и сохраняет снимки в игнорируемую папку `artifacts/`. Переменная `APP_URL` позволяет проверить размещение в подпапке, например `APP_URL=http://127.0.0.1:3001/CSM/ node tests/browser.mjs`.

## Содержимое и ограничения

Данные событий: `public/data.js`. Год в задании не указан: принят 2026 по текущему сезону. Время, адреса, программа, цены и ссылки регистрации не предоставлены и не выдуманы. Экспорт календаря использует даты без времени.

Сайт кейсов: https://sber-northwest-casebook.tenderlion1.chatgpt.site/#practice

Материалы стиля: https://files.sberdisk.ru/s/k3OodMv51eGOhlx

Оба сайта пока заблокированы сетевым прокси среды (CONNECT 403), а «стиль.pptx» превышает лимит передачи инструмента 32 МиБ. По уточнённому выбору пользователя визуальная система повторяет композицию второго референса на тёмном фоне: крупный градиентный заголовок, асимметричная мозаика, киберкот и цветные блоки. Схема с узлами и панели управления удалены. Точки входа из мозаики ведут в существующие разделы. Версия в URL стилей и точки входа JavaScript обновлена, чтобы ранее загруженные файлы не смешивались с новой разметкой. `public/styles.css` содержит базовую вёрстку, `public/theme.css` — оформление по референсам. Вместо недоступной презентации использован отдельный скриншот киберкота. Изображения киберкота и логотипов Сбера и DTaaS очищены и масштабированы по приложенным скриншотам инструментом редактирования изображений; они находятся в `public/assets/`. Это обработанные изображения, не извлечённые оригиналы из PPTX. Шрифты предоставлены пользователем отдельно и подключены локально из `public/fonts/`.

Все 20 кейсов и 68 партнёров перенесены из двух предоставленных пользователем текстовых файлов в `public/content.js`. Поисковая логика — `public/catalog-data.js`, интерфейс каталогов — `public/catalog.js`. Контекст метрик (цель, заявление, MVP, пилот, качественный эффект) и незаполненные поля сохранены. Номера кейсов соответствуют исходнику, включая кейс 23 «Самокат». Упомянутые в исходнике остальные 7 проектов других регионов не были приложены и не добавлялись. Контакты и отдельные сайты партнёров не предоставлены; ссылки на сайт-источник ведут на общий кейсбук.

Приложение не содержит серверной регистрации, личных кабинетов и CMS. Сохранение избранного локальное; события не обновляются автоматически.
