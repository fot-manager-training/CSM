# Помощник по КВ

Кнопка «Чат-бот» находится в правом нижнем углу на всех пяти страницах. Чат автоматически подключает общую базу КВ; посетителю не нужно выбирать файл. Вопросы, ответы и история текущего диалога остаются в памяти вкладки. Окно использует голубой градиент сайта и белое поле ввода. Под полем размещены «Помощник по КВ» с примерами вопросов и ссылки на мероприятия, обучение CSM, бизнес-кейсы и партнёров. Скрепка позволяет открыть свою книгу КВ только для текущей страницы; общая база продолжает подключаться автоматически.

## Общая база

По прямому указанию владельца «КВ одно для всех» очищенная копия опубликована в `public/assets/kv/knowledge.json` и доступна посетителям сайта. В ней сохранены все 174 строки по 80 сочетаниям «КЭС + продукт», значения и адреса исходных ячеек. Внешние формулы, оригинальный Excel, серверные пути и ключи не экспортируются. При отсутствии API поиск выполняется в браузере по этой общей базе, без отправки вопросов на сервер.

Один продукт отображается одной карточкой. Полностью одинаковые условия объединяются с сохранением ссылок на все исходные строки: в книге 129 уникальных наборов условий и 45 повторных строк. Разные условия доступны в переключателе внутри карточки; до выбора варианта единственная ставка не назначается. Признак сегмента в исходной книге отсутствует.

Чтобы обновить общую базу, импортируйте новую книгу и выполните `node scripts/export-kv.mjs`, затем опубликуйте изменения сайта. Скрипт сохраняет только значения, подписи и адреса ячеек.

## Резервный режим по локальному Excel

Только если общую базу не удаётся загрузить, появляется возможность нажать «Выбрать КВ.xlsx» и открыть книгу на устройстве. После чтения файла доступны вопросы по компании и продукту, отдельным строкам, НДС и максимальному/минимальному ПВ или ФинРез. Ответ помечен «Поиск по файлу на устройстве · без ИИ».

Книга читается средствами браузера: распаковка XLSX и чтение сохранённых значений XML, без вычисления формул, макросов, загрузки внешних ссылок или отправки файла/вопросов на сервер. Данные не записываются в localStorage или IndexedDB и пропадают после обновления/закрытия страницы; кнопка «Удалить из чата» очищает файл и переписку сразу. На другой странице книгу нужно выбрать повторно. Поддерживается .xlsx до 32 МБ, до 64 МБ после распаковки, десяти листов и 5000 строк с исходными заголовками A1:H1. Нужен современный браузер с DecompressionStream для deflate-raw.

Это поиск по таблице, а не подключение DeepSeek. Если доступен сервер с готовой базой, выбор локального файла не требуется. Общая логика подбора условий находится в `public/kv-lookup.js` и используется обоими режимами; `public/kv-workbook.js` не содержит данных исходной книги.

## Данные

Для предоставленного `КВ.xlsx` импортированы 174 строки, 80 сочетаний «КЭС + продукт», 36 компаний. Исходный файл содержит один лист `Лист1` и восемь колонок: КЭС, продукт, MIN ПВ, ПВ,%, К приб,%, доля владения,%, НДС,% и ФинРез. Значения C показаны в рублях, D:H — в процентах; точность отображения процентов до шести знаков, числовые значения сохранены без округления в базе.

У одного продукта бывают несколько строк с различающимися ставками. Признак сегмента или группы условий в файле не указан. Строки не объединяются и не выбираются произвольно: помощник показывает варианты, НДС и адреса исходных ячеек. Уточнение «строка 92» выбирает конкретную строку. Перед определением единственной применимой ставки необходимо уточнить, чем отличаются группы условий.

Формулы содержат ссылки на внешний калькулятор. Импорт использует сохранённые в Excel результаты, не выполняет формулы, не открывает внешние ссылки и не пересчитывает книгу. Дата действия ставок и правило применения MIN ПВ отсутствуют. Помощник не предполагает формулу `max(MIN ПВ, сумма × ПВ)` и не выдаёт неподтверждённую сумму выплаты.

Оригинальная книга и серверная база с формулами не публикуются в `public/`. Каталог `server/private/`, Excel-файлы и `.env` исключены из Git. Приватная база имеет права 0600. Общая копия с числовыми значениями опубликована отдельно по указанию владельца, как описано выше. В API возвращаются выбранные строки с отформатированными значениями и адресами ячеек, без внешних формул.

## Локальный запуск

Нужен Node.js 20.6+; для однократного импорта — Python и openpyxl:

```sh
python -m pip install -r requirements-kv.txt
python scripts/import-kv.py /path/to/КВ.xlsx
npm start
```

По умолчанию база находится в `server/private/kv-knowledge.json`. Другой путь задаётся через `KV_KNOWLEDGE_PATH`. После повторного импорта сервер нужно перезапустить.

Без ключа работает точный поиск по таблице; интерфейс явно показывает этот режим. Можно искать продукт и компанию, уточнять НДС, выбирать строку и сортировать по максимальному/минимальному ПВ или ФинРез.

## Подключение DeepSeek

Ключ задаётся только в серверном секрете `DEEPSEEK_API_KEY`; используемая модель — `deepseek-chat` (`DEEPSEEK_MODEL` может её изменить). Для локального запуска можно создать игнорируемый `.env` из `.env.example`, заполнить его через редактор секретов и запустить:

```sh
node --env-file=.env server.mjs
```

Фиксированный адрес провайдера — `https://api.deepseek.com/chat/completions`. Доступ к `api.deepseek.com` должен быть разрешён в среде исполнения. Код не содержит ключа и не выводит его, вопросы или ответы в серверные логи.

Сервер передаёт модели не всю книгу, а до двенадцати подходящих строк и ограниченную историю диалога. Модель объясняет условия, а числа и карточки формирует сервер из таблицы. Ответ модели должен быть JSON с допустимыми ссылками на строки и без новых числовых утверждений. Ошибка провайдера, неподтверждённые ссылки или числовые выдумки переключают ответ на поиск по таблице с явной пометкой.

## Развёртывание

Общая база и поиск работают на GitHub Pages без сервера. Для пояснений DeepSeek нужен отдельный Node.js-сервис либо размещение всего сайта на Node.js:

1. Разместить код сервиса на выбранном сервере и приватно передать базу по `KV_KNOWLEDGE_PATH`.
2. Задать серверный секрет `DEEPSEEK_API_KEY` и проверить `GET /api/kv/status`.
3. Если сайт остаётся на Pages, указать полный URL API с `/api/kv/` в `public/kv-chat-config.js` и разрешить origin сайта в `KV_ALLOWED_ORIGINS`.
4. Для внутренних условий использовать среду и доступ, предназначенные для сотрудников. CORS и ограничение частоты запросов не заменяют контроль доступа.

Сервер запущен и проверен в облачной среде текущей сессии GPT. Инструкции запуска сохранены в черновике настроек среды. Постоянный публичный адрес API доступными инструментами не создан, поэтому опубликованный GitHub Pages пока не подключён к этому серверу. Реальное соединение с DeepSeek не проверено: серверный секрет и сетевой доступ ещё не активированы. Пока эти подключения отсутствуют, на статическом сайте работает поиск по автоматически загружаемой общей базе. Ключ в публикацию не входит.

## Проверки

`npm test` включает проверки поиска, сохранения вариантов, ссылок на строки, ответов DeepSeek на имитации API, отказа при недостоверном ответе, ограничений входных данных и доступа к приватной базе. Браузерная проверка: `node tests/kv-chat-browser.mjs` при запущенных сервере и Chromium с отладочным портом 9222. Она использует импортированную локальную книгу и режим поиска по таблице.

`tests/kv-local-browser.mjs` проверяет статический сервер без API: укажите его адрес через `APP_URL` и путь к оригиналу через `KV_WORKBOOK_FILE`. Проверяются все 174 записи и 1044 числовых значения/подписи относительно приватного импорта, ответы и варианты, отсутствие запросов с файлом или вопросами, некорректные файлы, удаление данных и все пять страниц при 320/390/1440 px.

`tests/kv-shared-browser.mjs` проверяет автоматическую загрузку общей базы без выбора файла на статическом сервере без API, одну карточку продукта с выбором обеих ставок, точные показатели, отсутствие POST-запросов с вопросами, все пять страниц при 320/390/768/1440 px и повторное открытие после обновления страницы. `kv-shared.test.mjs` проверяет полноту публичной базы и отсутствие формул/секретов.
